# אפליקציה ללימוד אוצר מילים בערבית

אפליקציית ווב ללימוד אוצר מילים בערבית בשיטת ה-SRS (Spaced Repetition System) המאפשרת למידה יעילה וחכמה.

## תכונות

- **מערכת אימות משתמשים**: התחברות, הרשמה, וניהול פרופיל (באמצעות Firebase)
- **בחירת קטגוריות ללמידה**: אפשרות לבחור קטגוריות מילים ספציפיות להתמקדות
- **תרגול מילים**: תרגיל התאמה בין מילים בערבית ותרגומן לעברית
- **מערכת SRS (Spaced Repetition System)**: למידה חכמה המתזמנת חזרות במרווחים אופטימליים
- **מעקב התקדמות**: אפשרות לראות את התקדמות הלמידה דרך פרופיל המשתמש

## טכנולוגיות

- **React**: לבניית ממשק המשתמש 
- **Firebase**: לאימות ואחסון נתונים
- **SheetJS (xlsx)**: לקריאת קובץ האקסל המכיל את אוצר המילים
- **Vite**: כמערכת בנייה ושרת פיתוח

## התקנה והפעלה

### דרישות מקדימות

- Node.js ו-npm מותקנים
- חשבון Firebase (עם הגדרת אימות באמצעות אימייל/סיסמה)

### הגדרת הפרויקט

1. **שיבוט מאגר הקוד**:
   ```bash
   git clone https://github.com/Shique88/arabic-test.git
   cd arabic-test
   ```

2. **התקנת תלויות**:
   ```bash
   npm install
   ```

3. **הגדרת Firebase**:
   קובץ הגדרות Firebase כבר קיים בפרויקט (`src/firebase/config.js`).
   
   אם ברצונך להחליף אותו במפתחות משלך:
   - צור פרויקט ב-Firebase Console
   - הפעל אימות באמצעות אימייל/סיסמה
   - צור מסד נתונים Firestore
   - החלף את המפתחות בקובץ `src/firebase/config.js`

4. **הפעלת שרת הפיתוח**:
   ```bash
   npm start
   ```
   האפליקציה תהיה זמינה בכתובת: `http://localhost:3000`

5. **יצירת גרסת הפצה**:
   ```bash
   npm run build
   ```
   קבצי ההפצה יישמרו בתיקיית `build`

## אוצר המילים

האפליקציה משתמשת בקובץ אקסל (`vocabulary.xlsx`) הממוקם בשורש הפרויקט. הקובץ מחולק לגליונות לפי סוגי מילים, ולכל מילה יש:
- תעתיק בעברית
- פירוש/תרגום
- מידע נוסף (יחיד/רבים, זכר/נקבה, וכו')

## אודות SRS (Spaced Repetition System)

מערכת ה-SRS מתזמנת חזרות על מילים במרווחים אופטימליים לשיפור זכירה לטווח ארוך. 
המערכת מתאימה את תדירות החזרות בהתאם לביצועי המשתמש:
- מילה שנזכרת בקלות - מרווח ארוך יותר עד החזרה הבאה
- מילה שנכשלת - מרווח קצר יותר לחיזוק הזיכרון
